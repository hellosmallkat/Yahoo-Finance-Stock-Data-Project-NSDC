# Overview

This repository contains my implementation of the **National Student Data Corps (NSDC) Yahoo Finance Stock Data Project**.

Financial markets generate enormous amounts of time series data that can be analyzed to identify trends, evaluate historical performance, and develop predictive models. In this project, I worked with historical stock market data retrieved through the **Yahoo Finance API**, applying the complete data science workflow from data acquisition and preprocessing to visualization and predictive modeling.

Throughout the project, I explored stock price behavior, engineered meaningful financial features, trained machine learning models, and evaluated forecasting performance. This project strengthened my understanding of financial analytics, time series data, and predictive modeling while providing practical experience working with real-world financial datasets. ([Northeast Big Data Innovation Hub][1])
